# Bug Record: BUG-2026-05-01-001

## Summary

- Title: Vercel Flutter web build fails on diagnostics compile errors
- Current status: `fix-attempted`
- Severity: `high`
- Owner: Codex
- Next command: `/sf-test --retest BUG-2026-05-01-001`

## Reproduction

- Preconditions:
  - Vercel production build for `shipglowz_app` on commit `e02c4e3`.
- Steps:
  1. Run the Vercel production build.
  2. Let `scripts/vercel-build.sh` execute `flutter build web --release`.
  3. Observe the Dart compiler output.

## Expected Behavior

- Flutter web compiles successfully and Vercel can publish the production deployment.

## Observed Behavior

- The Vercel build fails during `dart2js` compilation because diagnostics code has one nullable map type mismatch and one missing provider import.

## Evidence

- Vercel deployment: `dpl_6o1HLZyDudAXMxGw8dcRyFVAsFyw`
- Commit: `e02c4e3`
- Error: `lib/providers/providers.dart:766:56: Error: The argument type 'Map<String, Object?>?' can't be assigned to the parameter type 'Map<String, Object?>'.`
- Error: `lib/presentation/screens/onboarding/onboarding_screen.dart:943:17: Error: The getter 'appDiagnosticsProvider' isn't defined for the type '_OnboardingScreenState'.`
