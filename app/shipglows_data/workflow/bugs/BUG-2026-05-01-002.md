# Bug Record: BUG-2026-05-01-002

## Summary

- Title: Vercel Flutter web app starts as a blank gray page
- Current status: `fix-attempted`
- Severity: `high`
- Owner: Codex
- Next command: `/sf-ship BUG-2026-05-01-002`

## Reproduction

- Preconditions:
  - Open the deployed Flutter web app at `https://shipglowsapp.vercel.app/`.
- Steps:
  1. Load the production URL in a browser.
  2. Let `flutter_bootstrap.js` load `main.dart.js`.
  3. Observe the first visible app state.

## Expected Behavior

- The ContentFlow entry page renders visible content, or the app shows a recoverable auth/bootstrap error with diagnostics.

## Observed Behavior

- The page shell loads from Vercel, but the user sees a blank gray page instead of the app.

## Evidence

- `curl -I https://shipglowsapp.vercel.app/` returned HTTP 200 from Vercel.
- `curl -sL https://shipglowsapp.vercel.app/main.dart.js | rg "Must be overridden"` returned two compiled `UnimplementedError` callsites.
- [lib/main.dart](/home/ubuntu/shipglows_app/lib/main.dart): the root `ProviderScope` previously had no overrides for `sharedPrefsProvider` or `appDiagnosticsProvider`.
- [lib/core/shared_preferences_provider.dart](/home/ubuntu/shipglows_app/lib/core/shared_preferences_provider.dart): provider throws `UnimplementedError('Must be overridden in main')`.
- [lib/core/app_diagnostics.dart](/home/ubuntu/shipglows_app/lib/core/app_diagnostics.dart): provider throws `UnimplementedError('Must be overridden in main')`.
